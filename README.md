# arunkaushikdev.github.io

Personal portfolio of **Arun Datt Kaushik**, an app and software developer who takes on college projects, freelance and industrial work.

Live site: https://arunkaushikdev.github.io

Plain HTML, CSS and JS with no build step. GitHub Pages serves it straight from the `main` branch.

## Structure
```
index.html            # all sections
assets/css/style.css  # styles
assets/js/main.js     # animations (scroll reveal, typing text, tilt, counters)
assets/img/           # favicon, profile photo
```
